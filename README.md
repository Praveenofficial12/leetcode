## Problem-Solving Approach

For each problem, I focus on:

1. Understanding the problem clearly
2. Identifying the suitable algorithm or pattern
3. Implementing a simple and readable solution
4. Testing sample and edge cases
5. Analyzing time and space complexity
6. Optimizing the approach when necessary
